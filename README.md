# 苗懂 Miodon

面向 0–6 岁儿童家庭的「疫苗数据查询 + 智能接种日历 + 接种决策参考」Web 应用。

> 苗懂不做在线问诊、不售卖疫苗、不替代接种门诊医生判断。所有数据仅供参考，接种以门诊评估和疫苗说明书为准。

## 功能

- **智能接种日历**：输入宝宝出生日期，自动生成 0–6 岁全程接种安排（一类免疫规划 + 推荐二类疫苗），标注已种 / 即将到期 / 逾期可补种，支持多宝宝档案。
- **疫苗数据查询**：每种疫苗包含——预防什么病（疾病介绍 / 传播途径 / 危害）、接种程序时间轴、厂商产品（商品名 / 厂家 / 工艺 / 参考价）、不良反应与居家处理、禁忌与暂缓。
- **厂商临床数据**：每个产品列出关键临床测试数据——终点指标、结果、样本量与人群、研究设计（III 期 RCT / 免疫桥接 / 说明书数据）、随访、来源；数据分三级标注：`已发表临床研究` / `疫苗说明书数据` / `待补充核实`（不编造数据）。
- **厂商对比**：多厂商疫苗（如 13 价肺炎 4 家、EV71、轮状、流感等）行=指标、列=产品横向对比表。
- **自费方案规划 + 智能排针**：三套预设方案（免费基础/安心精选/省心联合）或逐项勾选；引擎自动处理联合疫苗替换（打五联自动移除免费百白破/IPV/Hib 剂次）、互斥锁定、同日可接种提示，并实时统计总剂次、自费费用区间、预防疾病数。
- **「这种情况能不能打」速查**：湿疹、黄疸、早产、先心、哮喘、惊厥、免疫缺陷、丙球使用等 12 类特殊状况，依据《特殊健康状态儿童预防接种专家共识》给出结论与依据。
- **接种知识库**：11 条常见误区辟谣、接种前后准备清单（可勾选）、家庭「免疫茧」建议、疫苗成分名词解释。
- **日历导出与年度提醒**：一键导出 `.ics` 导入手机日历（提前 1 天闹钟）；流感疫苗每年流感季自动生成提醒。
- **接种记录**：标记已种（日期、产品、门诊、批号、费用），接种后反应记录（症状、体温、处理），附常见反应居家护理指南和「红旗症状 → 立即就医」提示。
- **本地优先**：所有数据保存在本设备浏览器 localStorage，无需注册、不上传服务器；支持 JSON 导出 / 导入备份。

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 构建纯静态产物到 dist/
npm run preview  # 预览构建产物
```

技术栈：Vite + React 19 + TypeScript + Tailwind CSS + react-router-dom（HashRouter）+ date-fns + lucide-react。构建产物为纯静态文件，可部署到任意静态托管 / OSS + CDN。

## 知识库数据来源

- 《国家免疫规划疫苗儿童免疫程序及说明（2026 年版）》（国家疾控局、国家卫生健康委，国疾控卫免发〔2026〕16 号）
- 百白破程序调整通知（国疾控卫免发〔2024〕20 号，2025-01-01 实施）、HPV 疫苗纳入国家免疫规划通知（2025-11-10 实施）
- 中国疾控中心免疫规划指南与疫苗接种专家共识
- 各疫苗官方说明书
- 公开发表临床研究（EV71 疫苗：Zhu 等 Lancet 2013;381:2024 / NEJM 2014;370:818 / NEJM 2014;370:829；五价轮状 REST 研究 Vesikari NEJM 2006;354:23；乙脑 SA14-14-2：Bista Lancet 2001;358:791 / Hennessy Lancet 1996;347:1583；卡介苗 Colditz JAMA 1994;271:698；HPV 疫苗 Qiao JNCI 2020;112:145 / Joura NEJM 2015;372:711 等）
- WHO 各疫苗立场文件

**数据维护说明**：知识库数据最近一次全网核实截止 **2026 年 9 月**。价格为各地常见参考价，会随政策和招标变化；免疫程序以国家疾控局最新文件为准；临床数据以来源文献/说明书为准，新上市产品的真实世界数据标注「待补充核实」，应在核实后更新。欢迎通过 Issue 指出过时或错误数据。知识库位于 `src/data/`：

- `vaccines.ts` — 疫苗与免疫程序、反应、禁忌
- `products.ts` — 厂商产品与临床数据
- `diseases.ts` — 疾病库
- `reaction-guide.ts` — 接种后反应居家处理指南
- `conditions.ts` — 特殊健康状态接种速查
- `knowledge.ts` — 误区辟谣、接种清单、免疫茧、成分名词

排针引擎在 `src/lib/planner.ts`（联合疫苗替换规则、方案预设、排期与统计）；`.ics` 导出在 `src/lib/ics.ts`。

## 免责声明

本应用仅提供疫苗科普信息与接种安排参考，不构成医疗建议。宝宝有发热、急性疾病、早产、免疫问题或特殊健康状况时，请在接种前告知接种医生并遵其判断。
